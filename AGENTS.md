# AGENTS.md

SVG profile cards rendered from a `Stats` snapshot of a user's GitHub contributions. Decisions and their reasons are in `docs/decisions/`. `README.md` is user-facing; development notes belong here. Read the relevant one before changing direction on the language, hosting, data source, counting rules or SVG constraints.

## Layout

- `action.yml` and `src/action/`, `src/cli/action.ts`: the GitHub Action (decision 0011).
- `src/github/`: GraphQL transport, raw fetch and the avatar-embedding snapshot. `src/stats/`: the `Stats` type, aggregation and fixture loading.
- `src/designs/<category>/<ID>-<slug>.ts`: one design per file. List it in the folder's `index.ts`. Category-only helpers go in `_shared.ts`; helpers for every category go in `src/kit/svg.ts`.
- `fixtures/`: `garysassano.json` is real data, used for the README and the catalog; `sample-small.json` is a tiny synthetic edge case.
- `gallery/`: generated by `pnpm gallery`. Never edit it by hand.

## Commands

Tools come from `mise.toml`. Node runs the TypeScript sources directly, with no build step.

```sh
pnpm check                            # Biome, tsc, Prettier on Markdown, Vitest
pnpm gallery                          # render every design into gallery/ (DEFAULT_FIXTURE in src/stats/fixture.ts)
pnpm gallery sample-small --only A01  # render one design from another fixture
pnpm fetch <login> --out data.json    # fetch a real snapshot (GITHUB_TOKEN, else the gh CLI login)
gh actions-lock --ignore-local-actions --no-narrow  # after changing a workflow: refresh .github/workflows/actions.lock
```

## Rules for designs

- Follow `docs/decisions/0005-svg-rules-for-github-readmes.md`: self-contained SVG, system fonts, at most 840 px wide, dark and light, deterministic.
- `render(stats, theme)` reads only its arguments. It must not read files, the clock, randomness, or contain user-specific literals. When a design has to choose something, it uses a rule stated in `idea`.
- `render(stats, theme, options)` honours `options.outcomes` (decision 0009) through `src/kit/outcomes.ts`; a design that can't render a level lists the levels it can in `outcomes`.
- Ids are permanent. Never renumber or reuse one; a retired id goes in `RETIRED` in `src/designs/index.ts`.
- A variant of an existing design is a setting of it (`settings` and `examples`, decision 0012), not a new id.

## Definition of done

- `pnpm check` passes: Biome, `tsc --noEmit`, Prettier on Markdown, and Vitest. The tests render every design in both themes from all three fixtures.
- After changing a design or a fixture, run `pnpm gallery` and commit the regenerated `gallery/`.
- For a visual change, look at a screenshot of the SVG (dark and light) rather than trusting the markup.

## Environment

On the owner's WSL machine memory is tight. Run heavy commands under `systemd-run --user --scope -p MemoryMax=…`, and run Vitest with `--maxWorkers=2` or fewer.
