# 0008 · The name: tributary

Date: 2026-11-07

## Decision

The project is called **tributary**.

## Why

A tributary is a smaller stream that feeds a larger river. The cards show exactly that: individual contributions flowing upstream into other people's projects and organizations. The name is short, easy to say, free on GitHub under the owner's account, and not tied to one output format (cards, a page, a JSON feed).

## Rejected

- **`gh-stats`**, the working title. It's generic, already used by many repositories, and says nothing about the angle: upstream contributions rather than personal totals.
- **`upstreamed`.** It's accurate, but reads as a past-tense status rather than a name.
- **`footprint`.** It's too general, and is used widely for carbon and cloud cost tools.
- **`patchwork`.** It's an established Linux kernel patch-tracking tool.
